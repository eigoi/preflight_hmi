# UAV Pre-Flight HMI Prototype v0.3

v0.3では「説明を読ませる」のではなく「操作そのものを減らす」方向に変更しました。

## 主な変更

### 1. 現在地を自動取得
ページを開くと位置情報を取得し、許可された場合は地図を現在地へ移動します。

離着陸地点がまだ未設定の場合は、現在地を離着陸地点の初期値として設定します。
このマーカーはドラッグで修正できます。

位置情報を拒否した場合でも利用できます。

### 2. 離着陸地点設定を原則自動化
- 現在地が取れた場合: 現在地を初期値
- 現在地が取れない場合: 経路始点を初期値
- 必要な場合のみ「離着陸地点を変更」
- 黒いマーカーをドラッグして修正可能

### 3. 経路操作を簡略化
以前:
1. 経路入力開始
2. 点をクリック
3. 経路確定
4. 離着陸地点設定
5. 地点クリック
6. 分析ボタン

v0.3:
1. 「経路を描く」
2. 地図上をクリック
3. 「経路を確定して分析」

または、2点以上入力後に地図をダブルクリックしても確定できます。

### 4. 分析を自動化
経路を確定した時点で自動分析します。
離着陸地点マーカーを動かした場合も自動で再分析します。

### 5. 画面上の説明を削減
長いステップ説明を削り、
- 離着陸地点
- 経路
- 分析状態
の3つの小さな状態表示だけにしました。

## 起動

```bash
python3 -m http.server 8000
```

Windows:

```bash
python -m http.server 8000
```

ブラウザ:

```text
http://localhost:8000
```

## 現在地取得
Geolocation APIは localhost または HTTPS 環境で使用してください。

画面上には表示されません。
