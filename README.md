# UAV Pre-Flight HMI Prototype v0.2

v0.1から、ユーザーが操作手順を理解しやすいようにUIを整理し、現在地表示を追加しました。

## 追加したもの

- 画面上部に5段階の操作ガイド
  - 任意: 現在地表示
  - 1: 飛行経路
  - 2: 離着陸地点
  - 3: 分析
  - 4: 現地確認
- 入力状況の表示
- 次に何をすべきかを画面上で案内
- 現在地取得ボタン
  - ブラウザの Geolocation API を利用
  - 現在地と位置精度の円を地図上に表示
- Generated Checks の文章構成を
  - 地図から分かったこと
  - 現地で確認すること
  - 問題があった場合
  - 地図情報の限界
  の順に変更
- Traceability は通常表示ではなく折りたたみ式にして、運航者向け画面を読みやすくした

## 現在地について

現在地表示は任意です。現在地は予定飛行経路や離着陸地点として自動設定されません。

ブラウザの位置情報機能を使用します。通常、以下の環境で利用できます。

- `http://localhost:8000`
- HTTPSで配信されたページ

ブラウザから位置情報利用の許可を求められたら「許可」を選択してください。

## 起動

```bash
python3 -m http.server 8000
```

Windowsで `python3` が使えない場合:

```bash
python -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000
```

## 操作手順

1. 必要なら「現在地を表示」
2. 「1. 経路入力開始」
3. 地図上を2点以上クリック
4. 「経路を確定」
5. 「2. 離着陸地点を設定」
6. 地図を1回クリック
7. 「3. 分析を実行」
8. 右側に出た項目を現地で確認

## 研究上の境界

- 200 m は法令上の距離、安全距離、SORA上の正式なバッファではありません
- 地図上に対象がないことは、実環境に障害物がないことを意味しません
- Safe / Unsafe判定はしません
- Utility infrastructureはケーススタディです
